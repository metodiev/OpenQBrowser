The CSS cascade

Specificity

Class selector: specificity 0,1,0.

Id selector wins: specificity 1,0,0.

An inline style wins over both.

But !important beats the inline style too.

Inheritance

The parent sets a purple colour and an 18px size. This child inherits both and only adds bold.

Presentational attributes

The bgcolor attribute is a presentational hint, so the stylesheet rule above wins; the width attribute, which no rule overrides, is applied as a 400 pixel width.

Media queries

This box has an 8 pixel padding on a narrow viewport and a 20 pixel padding with a green background once the viewport is at least 600 pixels wide.

Lengths and units

The parent is 20px. This spans 2em, so 40px. This is 150%, so 30px.
A width of 50% is resolved against the containing block.
