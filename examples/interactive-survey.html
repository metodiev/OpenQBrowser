Overview

This page exercises the parts of the engine a real page uses: a header, navigation, several sections, a form and a table. If it renders correctly, block layout, inline layout, the cascade and table display types are all working.

  • Block boxes stack vertically, with collapsed margins between them
  • Text breaks into lines inside each section
  • The table below uses display: table and its relatives
