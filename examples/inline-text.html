Inline text

Line breaking

This paragraph is 360 pixels wide, so the line breaker has to decide where to break each line. It breaks between words, never in the middle of one, which is why a single very long word would overflow rather than be split.

Inline formatting

Bold, italic, monospace, uppercase, letter spaced, struck through, and underlined text all sit on the same line, because each of them is an inline element.

Font sizes

small large 32px — mixed sizes on one line share a baseline.

Justified text stretches the spaces between words so that both edges of the paragraph line up. This sentence is long enough to wrap, which is what makes the justification visible.
